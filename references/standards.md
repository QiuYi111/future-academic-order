# 学术中文规范（源自 benzi.md）

## 句子成分分析规范

### 基础拆句法
将句子按主谓宾拆解，修饰成分另起一行缩进：

```
主语 谓语 宾语
  定语 → 修饰主语
  状语 → 修饰谓语
```

### 拆句示例
**原文：** "编码方式是直接决定成像系统中时空分辨率的主要因素，设计最优化光学编码，能够更加精准地提取神经成像的低维本征结构，从而获得更高的神经元采样带宽和成像质量。"

**分析：**
```
编码方式 是 直接决定成像系统中时空分辨率的主要因素
设计最优化光学编码 能够 更加精准地提取神经成像的低维本征结构
  → 从而获得更高的神经元采样带宽和成像质量
```

## 称谓规范

### 按场景处理
- 基金/项目书中避免使用 "我们" → 改为 "本项目" / "本课题" / "本研究"
- 基金/项目书中避免使用 "我" / "笔者" → 改为 "申请人" / "本项目负责人" 或直接省略
- "本课题组" 可用，但通常不如 "本项目" 正式

论文中不必机械删除 "我们"。如果期刊或导师风格允许，少量使用 "我们" 可以保留；正式中文论文通常优先用 "本文"、"本研究" 或省略主语。

### 替换对照表
| 原文 | 改写 |
|------|------|
| 我们提出了一个方法 | 本项目拟提出一个方法 |
| 我们的实验结果表明 | 实验结果表明 |
| 我们采用深度学习 | 本研究采用深度学习 |
| 我认为 | 申请人认为 |

上表主要适用于基金/项目书。论文润色时，应根据语境改为 "本文提出"、"实验结果表明" 或 "本研究采用"。

## 语态规范

### 主动句优先
中文基金/论文材料以主动句为正格。

**前：** "光线可以从物体平面向像平面追踪，这是镜头设计中用于像差分析的首选方式"
**后：** "光线从物体平面向像平面追踪是像差分析的首选方式"

### 正序优先
主语尽量前置，避免长状语堵在句首。

### 零冗余连接词
- 包含 "此外" → 多数情况可以直接删；若承担段落递进功能，可以保留或换成更具体的连接
- 包含 "值得注意的是" → 直接说内容
- 包含 "为了……的目的" → "为了……"
- 包含 "在……的情况下" → 多数情况可以删
- 包含 "通过……的方式" → "通过……"

## 段落密度标准

### 密度检查
- 如果一个句子去掉后段落意思不变 → 删除
- 如果一个定语去掉后核心意思不变 → 考虑删除
- 如果两个词表达同一个意思 → 保留一个

### 句子长度
长句不是问题，绕弯才是问题。句子可以长，但主谓宾必须清晰，修饰不能嵌套超过两层。

## 标点规范

### 中文 vs 英文标点
全部使用中文标点：
- 逗号：`，`
- 句号：`。`
- 冒号：`：`
- 分号：`；`
- 引号：`""`（中文双引号）
- 括号：`（）`

### 逗号位置
- 长状语后是否缺逗号？
- 主语过长时是否需要逗号断句？
- 并列项之间逗号是否一致？

## 不同位置的写作风格

| 位置 | 风格 | 判断标准 |
|------|------|----------|
| 话题发起 | 简洁、有力 | 一句话能说清楚就不写两句 |
| 内容展开 | 准确、详尽 | 术语精确、逻辑完整、不留歧义 |
| 总结收束 | 凝练、有分量 | 不做重复陈述，点出创新或价值 |
